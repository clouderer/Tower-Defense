# Tower Defense

**CPU Overload: Tower Defense** is a motherboard-inspired tower defense game. Defend digital pathways from waves of cyber threats by placing specialized defensive towers.

## Install and run

Install Python 3.10 or newer, then open a terminal in the `Tower-Defense` folder and run:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m program_files.app
```

On macOS or Linux, activate the virtual environment with `source .venv/bin/activate` instead.

## Play

- Choose **Play**, then select the first map to start the campaign.
- Choose **Tutorial** on the map selection screen for guided lessons.
- Press **Space** or click the bottom banner to start a ready wave.
- Press **S** or click the skip banner to start the next wave while existing enemies continue.
- Press **1–4** to select a tower for placement, **Q** to cancel placement, and **P** to pause or resume.
